# 岩﨑電気工事 工事写真DX V2.1

現場で「工事→作業→施工前/中/後→撮影」を行い、写真を自動分類するスマホ向けPWA試作版。

## V2機能
- 工事登録（工事番号・住所・担当者）
- 標準作業分類
- 作業追加
- 施工前／施工中／施工後
- コメント
- 写真自動分類
- 写真番号・日付を含むファイル名
- 写真一覧
- 工事別ZIP出力
- 全工事ZIP出力
- PWA対応

## プロジェクト方針
Phase 1: 現場撮影・分類
Phase 2: 電子小黒板・GPS・撮影漏れチェック
Phase 3: 写真台帳Excel/PDF
Phase 4: 事務所・現場のクラウド共有


## V2.1 更新内容
- 撮影フローを「工事 → 場所（階数・部屋名/場所） → 作業 → 施工前/施工中/施工後 → 撮影」に変更
- 作業選択から施工前・施工中・施工後の重複項目を削除
- 工事ごとに階数・部屋名/場所を登録可能
- 写真ファイル名に階数・部屋名/場所を追加
- ZIP出力も「工事/階数/部屋名・場所/作業/施工段階/写真」の構成に変更
