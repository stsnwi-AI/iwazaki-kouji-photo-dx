# 岩﨑電気工事 工事写真DX V3.9.3

V3.9.2を基準に、黒板位置・黒板サイズを写真ごとに後編集できるよう変更。

- 写真編集に「黒板位置（左下／右下）」を追加
- 写真編集に「黒板サイズ（小／中／大）」を追加
- 撮影時の黒板位置・サイズを写真ごとに保存
- ZIP／Ver43 Excel出力時は各写真に保存された位置・サイズを使用
- 「提出」の一括黒板サイズ変更欄は削除
- 元写真は変更せず、出力時に黒板を再生成
- V3.9.2までの既存写真は、位置=左下、サイズ=現在の標準設定をフォールバックとして使用


V3.9.4: 電子小黒板の文字ウェイトを統一。工事件名・工事場所の値、施工者名を含め、黒板内文字を太字基準に統一。

V3.9.4をベースにホーム画面用アイコンを追加。manifest・iPhone用apple-touch-icon・PWAキャッシュを更新。写真撮影・ZIP・Excelのロジックは変更していません。

V3.9.6: ボタン押下表示、写真順移動の更新件数削減、ZIP/Excelの進捗表示を改善。
