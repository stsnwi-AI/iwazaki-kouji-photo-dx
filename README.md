# 岩﨑電気工事 工事写真DX V3.8.5

V3.8.3の棟＋階数別シート、Ver43様式、1ページ幅印刷、記載欄仕様を維持し、Excelの連続出力を安定化した版です。

## V3.8.5修正
- Excel出力中はボタンをロックし、二重実行を防止
- 毎回、内蔵Ver43テンプレートを新しいJSZipインスタンスへ展開して生成
- 生成後の一時Blob URLは60秒保持してから解放
- ダウンロード名に時分秒を付加し、連続出力でも同名衝突を避ける
- 生成処理はtry/finallyで必ずロック解除
- PWAキャッシュをV3.8.5へ更新

## 維持仕様
- 表紙＋Ver43アルバム様式
- 用語集シートなし
- 棟→階数→部屋名→場所
- 棟＋階数ごとに別シート
- 横方向1ページ幅に合わせて印刷
- 右記載欄は左揃え：年月日／場所／内容／※コメント本文
- 場所・内容が長い場合は「／」を優先して改行
- 黒板あり／黒板なしを出力時に選択


## V3.8.5 修正
- ExcelワークシートXMLの pageSetup をOOXMLの正しい要素順に挿入するよう修正。
- 横方向1ページ（fitToWidth=1）、縦方向自動（fitToHeight=0）は維持。
- sheet2.xml / sheet4.xml / sheet5.xml 等でExcelの修復メッセージが出る原因を修正。
