## V3.10.28【開発・検証版】 JS表5-2に基づく写真区分別の記載項目切替

- 対象：日本下水道事業団（JS）令和6年4月『工事記録写真電子管理要領』表5-2（土木・建築・建築機械・建築電気）。
- 写真区分9種類に対し、工種・種別・細別の「○ 記入必須／△ 記入可能な場合は記入／× 原則空欄」を切り替えるルールを実装。撮影・写真編集で同じ制御を行う。
- ○は未入力で撮影・編集保存を進めない。△は入力欄を表示。×の入力欄は非表示にし、黒板への描画対象から外す。

- 現場を開くと各写真の保存済み設定を読み戻します。写真間で異なるチェックは「—」、位置・サイズは「写真ごとに異なる（維持）」で表示します。
- 一括適用前の変更は「未適用」と表示し、写真ZIP・Excel出力を止めて適用を案内します。
- 混在項目は変更しなければ写真ごとの設定を保持します。一括適用は事前確認後、単一トランザクションで保存します。
- 設定適用後は作成済み提出ファイルの保存欄を閉じ、再出力を必要とします。
- 保存設定の再表示、混在値保持、未適用時の出力停止、適用キャンセル、再読み込み後の保持、Excelの実際の黒板描画への設定引き渡しを自動検証しました。
