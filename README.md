# 岩﨑電気工事 工事写真DX V3.8

## V3.8 スマホ完結・Excel直接出力
- 現場画面の「提出」に「工事写真台帳Excelを出力」を追加。
- スマホ内の写真・台帳順・写真情報から `.xlsx` をブラウザ内で直接生成。
- 出力時に OK=黒板あり / キャンセル=黒板なし を選択。
- VBA / .bas / PowerShell / .bat は不要。PCでは完成したExcelを開くだけ。
- 従来の「写真ZIPを出力」も継続。
- ⑤台帳の写真順（ledgerOrder）をExcelの写真順に使用。
- 写真編集後は修正済みの階数・部屋名・場所・作業・工程・コメントをExcelへ反映。

## 注意
- Excel直接出力はV3.8で新規実装した機能です。ブラウザ内でOpen XML形式の.xlsxを生成します。
- 実際のスマートフォン機種・会社PCのExcelでの最終表示は環境差があるため、初回は数枚で試験出力してください。
- IndexedDB名 `iwasaki_v2` を維持しているため、同一オリジンで更新すれば既存データを引き継ぐ設計です。
